# Portfolio de Worzz

Portfolio personnel de Worzz, développeur web en apprentissage. Le site présente son parcours, ses projets et ses moyens de contact.

## Aperçu

Le portfolio comprend quatre pages :

- **Accueil** (`html/index.html`) : présentation rapide et accès aux projets.
- **Projets** (`html/projets.html`) : présentation des réalisations, dont un site de garage en préparation.
- **À propos** (`html/about.html`) : parcours et démarche d’apprentissage.
- **Contact** (`html/contact.html`) : liens vers l’adresse e-mail et TikTok.

## Technologies

- HTML
- CSS
- JavaScript (le fichier `js/script.js` est actuellement prêt à être utilisé)

Les animations et le défilement utilisent les possibilités natives de CSS. Three.js est envisagé pour une évolution future.

## Lancer le site

Aucune installation ni compilation n’est nécessaire. Ouvre simplement `html/index.html` dans un navigateur. La navigation entre les pages fonctionne avec leurs liens locaux.

## Structure du projet

```text
portfolio/
├── css/       # Feuilles de style des pages
├── html/      # Pages du portfolio
├── img/       # Logo et images
├── js/        # Scripts JavaScript
├── README.md
```
